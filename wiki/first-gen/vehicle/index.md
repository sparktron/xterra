# Nissan Xterra wiki: reference, first generation, 2000-2004

[Section index](../index.md)

Hand-curated reference for the 2000-2004 Nissan Xterra [S1][S2], written from Nissan's service manuals and NHTSA data. Every number cites a source listed at the bottom of its page. This section covers only the first-generation truck.

## Engines and model codes

Nissan's 2004 manual decodes the model code like this [S2]:

| Position | Code | Meaning | Source |
|---|---|---|---|
| Engine | BG | KA24DE four-cylinder | [S2] |
| Engine | LP | VG33E or VG33ER V6 | [S2] |
| Drive | A / N | 2-wheel drive / 4-wheel drive | [S2] |
| Trim | E / F | XE / SE | [S2] |
| Transmission | F / A | 5-speed manual / 4-speed automatic | [S2] |
| Fuel system | E / R | Multiport fuel injection / multiport fuel injection and supercharger | [S2] |
| Market | U / N | U.S.A. / Canada | [S2] |

Displacement: the KA24DE is 2,389 cm³ (145.78 cu in), and the VG33E 3,275 cm³ (199.84 cu in) [S3].

## Fluids at a glance (2000 manual)

Approximate capacities from the 2000 service manual. Later years can differ: the 2004 manual gives the KA24DE less oil. Check the [oil change guide](guides/engine-oil-change.md) and your own year's manual [S1][S4].

| Fluid | KA24DE | VG33E | Source |
|---|---|---|---|
| Engine oil, drain and refill with filter | 3.9 L (4-1/8 US qt) | 3.3 L (3-1/2 US qt) | [S1] |
| Cooling system, with reservoir | 9.25 L (9-3/4 US qt) | 10.95 L (11-5/8 US qt) | [S1] |
| Manual transmission | FS5W71C: 2.0 L (4-1/4 US pt), API GL-4 75W-90 | FS5R30A: 2.4 L (5-1/8 US pt) 2WD, 5.1 L (10-3/4 US pt) 4WD, API GL-4 75W-90 | [S1] |
| Automatic transmission | | 8.3 L (8-3/4 US qt) 2WD, 8.5 L (9 US qt) 4WD, Nissan Matic "D" | [S1] |
| Transfer case (TX10A) | | 2.2 L (2-3/8 US qt) | [S1] |
| Differential | 1.5 L (3-1/8 US pt) | Front (4WD) 1.5 L (3-1/8 US pt); rear 2.8 L (5-7/8 US pt) | [S1] |
| Power steering | 0.9-1.0 L | 1.0-1.1 L | [S1] |

Differential oil is API GL-5; a limited-slip differential takes only Nissan-approved LSD gear oil, API GL-5 SAE 80W-90 [S1]. The 4WD's free-running (auto-locking) hubs take Genuine Nissan grease or an equivalent [S1].
